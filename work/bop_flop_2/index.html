Bop or Flop 2.0: Advanced ML Methods for Spotify Song Popularity Prediction¶

Abstract¶

In recent years it has become increasingly easy for individuals to monetise music, with digital streaming services seeing a dramatic rise in song production. Despite this, the classic industry problem remains; can we predict if a song will be successful? Previous work by Coake (2025) explored a quantitative solution via. semi-supervised machine learning, although this did not yield commercially viable results. In this paper, we introduce new data sources and advanced statistical techniques, including Bayesian inference, to improve the prediction of song popularity using Spotify Audio Features and beyond.

Introduction¶

Case Study

This paper is a second iteration of the case study initially stated by Coake (2025):

"An up-and-coming music record label receives large numbers of demo submissions from artists on a regular basis. Executives at the company are seeking a data-driven solution which automates the demo selection process; focused primarily on maximising commercial success and profitability for the record label."

Aims and Objectives

The objective is to use regression modelling to maximise both the predictive likelihood of a song being popular, and the financial risk associated with model accuracy. For continuity, we reuse the dataset collated by Pandya (2023) and modelled by Coake (2025). We also introduce a new dataset gathered by Freyberg (2023), which includes historical streaming data, to enrich the reliability of a defined popularity threshold.

Quantification of financial risk remains consistent with Coake (2025) to ensure comparability between models:

"Quantify the financial risk ... This is best represented by the confusion matrix of the final classification model:

  • True Positive: The demo is successful by both prediction and reality (+2).
  • False Positive: The demo is not successful in reality, but predicted so (-1).
  • True Negative: The demo is unsuccessful by both prediction and reality (+0).
  • False Negative: The demo is successful in reality, but is not predicted so (-2)."

The key milestones for the project are:

  • Train an optimal frequentist logistic regression model using all model features.
  • Build a second logistic regression model with a Bayesian approach to account for uncertainty, and compare with the frequentist approach.
  • Optimise both models to achieve higher true positive prediction, lower financial risk, or both, compared to the conclusions made by Coake (2025).

Frequentist Logistic Regression¶

Rationale¶

For standard (frequentist) logistic regression, we build the model as $$p(y_i|X,\beta)=\phi(z),$$ where $y$ is the target variable, $X$ is the model features, $\beta$ is the feature coefficients, $z=\beta_0+\beta_1x_1 + ...+\beta_nx_n$ is the regression line, and $\phi = \frac{1}{1+e^{-z}}$ is the sigmoid (logistic) function.

We then maximise the likelihood function to estimate the (one) most optimal parameter $\beta$, opening up the ability to make informed predictions.

Why use Logistic Regression?

Coake (2025) uses a Random Forest classifier for song popularity prediction. This is a reasonable approach, however decision-based models are highly algorithmic and as such can be prone to overfitting. Conversely, logistic regression is a probabilistic model with a strong statistical foundation in its approach. Not only can it classify the target (song popularity), but it also provides a clear understanding of model features with the strongest effects; much deeper insights than the standard 'bop or flop' outcome.

Bayesian Logistic Regression¶

Rationale¶

For Bayesian logistic regression, we treat each $\beta$ from $z$ as random variables to find the probability of each possible (optimal) $\beta$. Derived from Bayes' Theorem of conditional probability, we formulate predictions as $$p(\beta_j|X,y_i)\propto p(y_i|X,\beta_j)\times p(\beta_j).$$

This births three unique probability distributions:
Prior $p(\beta_j)$ Initial understanding of the probability distribution for $\beta_j$.
Likelihood $p(y_i X,\beta_j)$ Model outputs as per frequentist approach
Posterior $p(\beta_j X,y_i)$ Updated probability distribution of $\beta_j$ after accounting for both likelihood and prior.
For logistic regression tasks, the posterior distribution cannot be derived mathematically in its initial form.
An approximation must be used to generate a posterior distribution (e.g. Laplace approximation).

Why Bayesian over the Frequentist approach?

Bayesian inference adds an extra layer of details over standard statistical methods by accounting for uncertainty. Using a frequentist logstic regression model we can obtain insight on the magnitude and direction of a feature's importance on classification. A Bayesian logistic regression model will output magnitude and direction in addition to the credible interval; the probability of a coefficient value lying between a given interval. Another benefit of the Bayesian approach is the concept of prior distributions. We can use previous knowledge and/or test hypotheses to establish a useful baseline for modelling.

    beta = pymc.Normal("beta", mu=0, sigma=1, shape=trn_f_balanced.shape[1])
    intercept = pymc.Normal("intercept", mu=0, sigma=1)

    # Regression line
    # Dot product to form B0 + B1X1 + B2X2 + ...
    line = intercept + pymc.math.dot(trn_f_balanced, beta)

    # Likelihood: Binary Target so Bernoulli distribution
    y_obs = pymc.Bernoulli("y_obs", logit_p=line, observed=trn_t_balanced)

Laplace Approximation¶

In order to make predictions and evaluate model performance, we need to define the posterior distribution via. approximation. There are multiple ways to do this, however we proceed with the Laplace approximation.

We have a Normal prior, $\beta_j \sim \mathcal{N}(0,1)$, so the posterior distribution is approximated at its local maximum, given by a combination of the prior and log-likelihood function; we know this to be Bernoulli.

The likelihood function, $$p(y_i|X,\beta_j) = \phi(z) = \frac{1}{1+e^{-(\beta_0+\beta_1x_1+...)}},$$

has the following Bernoulli log-likelihood for all observations $y_i$ : $$ln\: p(y_i|X,\beta_j) = \sum_{i=1}^{n}\: [\: y_i\: ln\: \phi(z) + (1-y_i)\:ln\:(1-\phi(z))\:].$$

We now maximise the posterior using the maximum a posteriori (MAP) estimate:

$$ MAP = \arg \max_{\beta_j}\: [\: p(\beta_j|X,y_i) \:] = \arg \max_{\beta_j}\: [\: ln\:p(y_i|X,\beta_j) + ln\:p(\beta_j) \:]$$$$ = \arg \max_{\beta_j}\: \sum_{i=1}^{n}\: [\: y_i\: ln\: \phi(z) + (1-y_i)\:ln\:(1-\phi(z))\:] - \frac{1}{2\sigma^2}||\beta||^2,$$

where $- \frac{1}{2\sigma^2}||\beta||^2$ is the log-likelihood of the Normal prior.

Posterior Coefficients¶






















Given we assume the distribution has only one maximum, we can class the collection of points above as the mean of the posterior distribution. In order to form an approximation for the (Normal) posterior distribution we need to find the covariance; we find this using a Hessian Matrix. These are special matrices used primarily to mathematically determine local minima and maxima for a multivariate equation. In a statistical context, the inverse of a Hessian Matrix is equal to the covariance (matrix) of a multivariate dataset. We omit the mathematical proof as it is not relevant to this task.


With mean and covariance defined we can build an approximated Normal posterior distribution, which can then be used for prediction.

Predictive Performance¶






















As we now have a posterior distribution $p(\beta_j|X,y_i) \approx \mathcal{N}(\mu,\sigma^2)$, we need to find the posterior predictive distribution in order to predict new data points. Gelman (2013) states that to make predictions $\breve{y}$ given observations $(y,\theta)$, the posterior predictive distribution is given by

$$p(\breve{y}|y) = \int p(\breve{y}|\theta)\: p(\theta|y)\: d\theta.$$
For the Spotify dataset, we wish to predict new data points $X_{new}$ (predict a song is popular, $y=1$), based on known observations. Therefore the posterior predictive distribution is

$$p(y_i=1|X_{new},X,y_i) = \int p(y=1|X_{new},\beta_j)\: p(\beta_j|X,y_i)\: d\beta. $$
This is equivalent to the likelihood function and the posterior distribution, so this can be simplified to

$$p(y_i=1|X_{new},X,y_i) = \int \phi(z)\: \mathcal{N}(\mu,\sigma^2)\: d\beta. $$
Unfortunately, this integral is not calculable and another approximation is required. Similar to the rationale of conducting the Laplace approximation for the posterior distribution, there are many different approaches. We proceed with an analytical approximation shown in texts such as Bishop (2006) which reduces the posterior predictive distribution to

$$\int \phi(z)\: \mathcal{N}(\mu,\sigma^2)\: d\beta \approx \phi \left( \frac{\mu}{\sqrt{1+\frac{\pi^2}{8}\sigma}} \right).$$
